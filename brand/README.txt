SOLNAIR LOGO KIT  ·  November 2026
Open Solnair-Logo-Kit.pdf first: it shows every version and which file to use where.

FOLDERS
  svg/                    Vector logos. Any size, never blurry. Best for the website, Canva, designers.
  pdf/                    The same vectors as PDF. Send these to printers (business cards, shirts, decals).
  png/<version>/          Transparent images in 3 sizes each (for Docs, Slides, Loom thumbnails, email).
  app-icon-and-favicon/   Browser-tab and app icons (favicon.ico, favicon.svg, apple-touch-icon-180.png, icon-192/512.png).
  social/                 Ready-to-upload profile photos, banners, link preview, email signature.

VERSIONS            horizontal, stacked (with AUTOMATION), wordmark, icon (sun), icon-small (sun under 40 px)
COLOURS             green (light backgrounds), reversed (dark/green backgrounds), black, white (one-colour jobs)
FILE NAMES          solnair-<version>-<colour>[-<width>px].<ext>

BRAND COLOURS       Solnair Green #2F9474 · Deep Green #1F5E4A · Night Green #173F33 · Mint #9FD3BF · Off-white #FAF8F3 · Ink #1E1E1C
FONTS               Unbounded Medium (logo, headlines) · Inter (everything else). Free on Google Fonts.
